## Handoff (shared by every agent in this repo)
- On start: read `handoff.md`. Resume from **Next step**. Do not redo **Done**.
- Then check the files. Work you find that is not in **Done**: read it, keep it, log it. Do not rewrite it.
- Proof = the command and the output you actually saw. If a command failed, write that.
- In **Done**, write which agent did each step. Never delete **Traps**; mark wrong lines as wrong.
- After each finished step and before any long one: update `handoff.md` (Goal, Done with proof, Next step, Traps, Last agent/time). Keep it under 60 lines. No secrets.
- If a limit may be close, write `handoff.md` first.
